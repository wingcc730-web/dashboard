# 🌸 個人天氣與交通儀表板

這是一個為日常資訊查看而設計的響應式網頁儀表板，整合屯門天氣、未來七天天氣預報、Google 日曆、香港公眾假期、九巴、港鐵巴士及輕鐵到站資訊。

網頁可透過 GitHub Pages 運行，並針對 iPhone、iPad 及電腦瀏覽器作自動尺寸調整，適合長時間開啟作為個人資訊板。

## 🌐 網頁連結

[開啟個人天氣與交通儀表板](https://wingcc730-web.github.io/dashboard/)

## ✨ 主要功能

### 🕒 即時時間及日期

- 顯示目前時間，包括時、分、秒
- 顯示公曆月份、日期及星期
- 顯示農曆節日標籤
- 時間每秒自動更新

### ☀️ 屯門天氣資訊

- 顯示屯門目前氣溫
- 顯示體感溫度
- 顯示紫外線指數
- 顯示相對濕度
- 顯示目前小時的降雨概率百分比
- 顯示今日最低及最高氣溫
- 顯示未來七天天氣預報
- 天氣資料每 60 秒自動更新

### 📅 Google 日曆及香港假期

儀表板整合以下 Google 日曆：

- Dating
- Travel
- Working
- 香港假期

不同日曆以不同顏色顯示，方便快速識別活動類別：

- 紫色：Dating
- 藍色：Travel
- 綠色：Working
- 紅色：香港假期

## 📱 響應式設計

網頁會按照裝置螢幕及瀏覽器視窗大小自動調整。

### iPhone 直向

- 天氣及交通改為上下排列
- 縮小頁面邊距
- 放大日期，方便閱讀
- 天氣資料改為單欄顯示
- 隱藏右上角農曆節日標籤，避免標題列過於擠迫

### iPhone 橫向

- 自動切換為緊湊資訊板模式
- 天氣及交通維持左右兩欄
- 自動縮小字體、卡片間距及月曆高度
- 顯示農曆節日標籤
- 預留安全區域，避免內容被 Dynamic Island 或螢幕圓角遮擋

### iPad

- 按照直向、橫向及實際視窗寬度自動調整
- 一般情況使用左右兩欄
- 分割畫面時會按可用空間重新排列
- 月曆及交通卡片會自動調整高度和間距

### 電腦瀏覽器

- 使用左右兩欄版面
- 儀表板自動置中
- 最大內容寬度受到限制，避免在寬螢幕上過度拉闊
- 縮小瀏覽器視窗時會自動切換版面

## 🔄 自動更新頻率

| 資料 | 更新頻率 |
|---|---|
| 時鐘 | 每 1 秒 |
| 天氣資料 | 每 60 秒 |
| 九巴到站資料 | 每 30 秒 |
| 港鐵巴士到站資料 | 每 30 秒 |
| 輕鐵到站資料 | 每 30 秒 |

當網頁切換到背景時，天氣及交通自動更新會暫停，以減少不必要的網路使用及電量消耗。

返回網頁後，系統會立即重新取得最新資料。
